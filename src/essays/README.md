# Reynard's essays

Each essay is one Markdown file in this folder. It appears on Reynard's Stump and gets its own page at
/stories/<file-name>/. The file starts with a short header:

    ---
    title: The essay's title
    date: 2026-11-20
    summary: One or two sentences for the list and for link previews.
    ---

then the essay in plain paragraphs, with a blank line between paragraphs. The byline is Reynard the Fox.
Also allowed: ## headings, **bold**, *italic*, [links](https://...), > quotes, - lists, and --- for a break.
